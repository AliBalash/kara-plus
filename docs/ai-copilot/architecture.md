# Kara Plus AI Copilot

Kara Plus remains the system of record. The browser calls Livewire, Livewire prepares compact verified facts, and Laravel calls Ajil privately. Ajil owns all provider keys, retry, cooldown, key rotation, and provider fallback. It is never called from JavaScript.

The first slice is read-only: Contract Brief, Dashboard Operations Brief, and Payment Queue Brief. Every model alert must map to a deterministic `fact_id`; unknown IDs are discarded server-side.

`ai_insights` caches validated output by normalized input hash and prompt version. `ai_runs` holds safe operational metadata only. A per-feature circuit breaker prevents repeated Ajil failures from creating request storms.
